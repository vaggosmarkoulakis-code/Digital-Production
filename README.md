# Markoulakis Digital Studio

Premium personal studio website built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion and Lenis.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Deploy To Netlify

Netlify settings:

- Build command: `npm run build`
- Publish directory: `.next`
- Node version: `22`

The repository includes `netlify.toml`, so Netlify should detect these settings automatically.

## Edit Content

Most editable website content is in:

- `app/page.tsx`
- `app/globals.css`
- `public/`
